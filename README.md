# Software Engineering Experiment 20

## Git Version Control Workflow

This experiment demonstrates version control using Git and GitHub.

### Modules
- Login Module
- Profile Module

### Workflow
1. Created separate branches for individual modules.
2. Developed changes in feature branches.
3. Created Pull Requests.
4. Merged branches into the main branch.
5. Created and resolved a merge conflict.

## Conclusion

Git and GitHub were used for version control, branch management, pull requests, merging, and conflict resolution.
